# Kitchen Stock Calculator (Калькулятор складских остатков)

Учебный консольный сервис на языке **Go**, созданный для отработки базовых конструкций языка, работы со структурами, указателями, обработкой ошибок и разделением кода на пакеты.

Программа имитирует учет продуктов на кухне ресторана: проверяет минимальные остатки, списывает и пополняет вес продуктов, а также рассчитывает общий вес и стоимость склада.

## 🚀 Как запустить проект

1. Откройте терминал и перейдите в папку проекта:
   ```bash
   cd ~/projects/kitchen_calc
   ```
2. Запустите программу без предварительной сборки:
   ```bash
   go run main.go
   ```
3. *(Опционально)* Скомпилировать готовый бинарный файл и запустить его:
   ```bash
   go build -o kitchen_calc
   ./kitchen_calc
   ```

## 🧠 Ключевые концепции Go, разобранные в проекте

### 1. Пакеты и правила видимости (`package inventory`)
* Код разделен на главный исполняемый пакет `main` и вспомогательный пакет `inventory`.
* **Правило экспорта:** В Go нет слов `public` и `private`. Если имя структуры, поля или метода начинается с **Заглавной буквы** (`Product`, `TotalPrice`, `Weight`), оно доступно из других пакетов. Если со **строчной** — видно только внутри текущей папки.

### 2. Структуры (`struct`) и срезы (`slice`)
* Вместо простых карт (`map`) для описания объекта с несколькими характеристиками используется структура `Product` (`Name`, `Weight`, `MinStock`, `PricePerKg`).
* Список всех продуктов хранится в динамическом массиве — срезе `[]inventory.Product`.

### 3. Методы: по значению против указателей (`*`)
* **Value Receiver `(p Product)`** (методы `TotalPrice`, `NeedsRestock`): получают *копию* структуры. Используются, когда данные нужно только прочитать, не изменяя оригинал.
* **Pointer Receiver `(p *Product)`** (методы `Restock`, `Use`): принимают *указатель* на реальный адрес структуры в памяти. Используются, когда метод должен изменить данные объекта (например, списать вес со склада).

### 4. Обработка ошибок (`error`)
* В Go ошибки возвращаются как обычное значение (метод `Use(kg float64) error`).
* Если операция прошла успешно, возвращается `nil` (пустота). Если произошла ошибка (попытка списать больше продукта, чем есть на складе), возвращается `errors.New(...)`.
* Проверка в коде всегда выглядит так:
  ```go
  err := products[0].Use(10.0)
  if err != nil {
      fmt.Println("Error:", err)
  }
  ```

## 🛠 Шпаргалка по командам терминала и Git

### Навигация в Linux (Ubuntu)
* `pwd` — показать полный путь к текущей папке.
* `ls -la` — показать список всех файлов в папке (включая скрытые, например `.git`).
* `cd имя_папки` — зайти в папку (`cd ..` — выйти на уровень выше, `cd ~` — перейти в домашнюю директорию).
* `mkdir имя_папки` — создать новую папку.
* `touch имя_файла` — создать пустой файл.
* `code .` — открыть текущую папку в редакторе VS Code.

### Работа с Git и GitHub
Ежедневный цикл сохранения изменений в облако состоит из 3 команд:
```bash
git add .                                   # 1. Подготовить все изменённые файлы к сохранению
git commit -m "docs: add detailed README"   # 2. Зафиксировать точку сохранения с описанием
git push                                    # 3. Отправить коммит на GitHub
```

Дополнительные полезные команды:
* `git status` — проверить, какие файлы были изменены, но ещё не закоммичены.
* `git log --oneline` — посмотреть компактную историю всех сделанных коммитов.
